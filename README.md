# 🛡️ OSINT Tool Pro

Современный веб-инструмент для OSINT-разведки с анимированным фоном.

## 🔧 Функции

- 🌐 **IP-локатор** — геолокация по IP
- 📞 **Phone-инфо** — информация по номеру телефона
- 🔍 **Соц-чекер** — поиск в 20+ соцсетях
- 🎯 **IP-логгер** — создание ссылок через Grabify

## 🚀 Запуск

Откройте `index.html` в браузере или перейдите на [GitHub Pages](https://ваш-логин.github.io/osint-tool).

## 📦 Технологии

- HTML + CSS + JS
- Canvas для анимированного фона
- Fetch API для запросов
- GitHub Pages для хостинга
